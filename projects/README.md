## 新增项目登记流程

1. 项目代码放到独立仓库（个人项目建议 `~/github_code/<name>`）。
2. 在本目录建 `<name>/README.md`，写清：一句话定位、代码路径、Git 远端、运行入口、关联设备/Bot。
3. 在上一级 `README.md` 与 `AGENTS.md` 的索引表里加一行。
