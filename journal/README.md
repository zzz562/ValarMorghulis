# Journal · 工作日志

本仓库的共享工作日志。**box 上的 bot、以及我自己的 Grok agent 都可能来写**，所以规则以「避免互相踩踏 / 减少冲突」为第一原则。

## 为什么放这里

- valar 是 box 上 bot 的全局指导源,box bot **读远端分支**获取指导;把日志放在同一仓库,决策与上下文和指导内容一起版本化、一起分发。
- 项目代码在各自独立仓库(如 WhaleTrail Lab),但**跨项目的角色/协作决策**属于 valar,记在这里。

## 规则(重要)

1. **一条记录一个文件**,命名 `journal/YYYY-MM-DD-<slug>.md`(slug 用短横线小写英文)。同一天多条就多建文件。
2. **只追加,不改别人的记录。** 要补充/更正,新建一条并在开头 `> 关联: <旧文件>` 引用,不要原地覆盖。
3. 每条记录开头写清 **作者**(是人、哪个 box bot、还是哪个 agent),便于多方协作追溯。
4. 写前先 `git pull --rebase`,写完小步提交、尽快推;避免长时间占着未推的改动。
5. **绝不写密钥 / token / 密码**。敏感值指向机器上的 `~/.openclaw/.env` 等,不落库。
6. 内容用中文即可,和仓库其余文档一致。

## 记录模板

```markdown
# <标题>

> 日期: YYYY-MM-DD ・ 作者: <人/bot/agent id> ・ 范围: <box角色规划 / whaletrail / …>

## 背景
## 决定
## 动作
## 待办 / 开放问题
```
