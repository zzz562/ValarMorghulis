# Journal · 工作日志

本仓库的共享工作日志。**Grok Bot 主机上的助手、以及开发期 agent 都可能来写**，所以规则以「避免互相踩踏 / 减少冲突」为第一原则。

## 为什么放这里

- valar 是运行期助手的全局指导源；把日志放在同一仓库，决策与指导一起版本化。
- 项目代码在各自独立仓库，**跨项目的角色/协作决策**记在这里。

## 规则(重要)

1. **一条记录一个文件**,命名 `journal/YYYY-MM-DD-<slug>.md`。同一天多条就多建文件。
2. **只追加,不改别人的记录。** 要补充/更正,新建一条并引用旧文件。
3. 每条记录开头写清 **作者**。
4. 写前先对齐远端,写完小步提交、尽快推。
5. **绝不写密钥 / token / 密码**。
6. 内容用中文即可。

## 记录模板

```markdown
# <标题>

> 日期: YYYY-MM-DD ・ 作者: <人/bot/agent id> ・ 范围: <box角色规划 / whaletrail / …>

## 背景
## 决定
## 动作
## 待办 / 开放问题
```
